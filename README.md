# Weather Report Dashboard 🌦️

An interactive Power BI dashboard that analyzes and visualizes weather data including 
temperature, humidity, wind speed, and air quality.  

## Features
- 📊 Daily and hourly weather trends  
- 🌡️ Temperature and humidity analysis  
- 🌬️ Wind speed patterns  
- 🌍 Air quality index visualization  
- 🎯 User-friendly filters and slicers  

## Tools Used
- Power BI (Data Modeling & Visualization)
- Weather API 
- DAX (Measures & Calculations)

## How to Use
1. Download the `.pbix` file.
2. Open it in Power BI Desktop.
3. Explore the dashboard interactively.
